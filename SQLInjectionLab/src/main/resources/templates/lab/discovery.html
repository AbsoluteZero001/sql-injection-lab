Directory Brute Force

隐藏目录与静态页面

本关故意保留了一批没有链接入口的目录和前端文件。目标是只通过 HTTP 状态码与页面内容，找到至少三个隐藏资源并读取其中标记。

挑战说明

提示：先查看 /robots.txt，再结合常见目录字典对本站进行枚举。返回 200、301/302 与页面标题差异都值得继续跟进。

需要寻找

  • 带站点标志的静态 HTML 页面
  • 备份或配置文件
  • 最终 flag 文件

常用工具

  • dirsearch / gobuster / dirb
  • ffuf
  • Burp Intruder

命令示例

dirsearch -u http://localhost:8080 -w wordlist.txt
gobuster dir -u http://localhost:8080 -w common.txt

建议字典

admin-panel
archive
backup
console
docs
old
private
staging
static
test
tmp

字典可以替换为 dirsearch 默认的 directory-list-2.3-medium.txt，实际隐藏资源不一定只使用上面这些名称。

目录扫描会发送大量请求，请把线程数调低，并在授权靶场上练习。
